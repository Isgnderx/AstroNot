# Təqdimat üçün vizual paket

53 şəkil, loqo və ikon faylı. Bəzi vizuallar həm SVG, həm PNG variantında verilib.

## Başlamaq

index.html faylını brauzerdə aç. Hər vizualın altında onun SVG, PNG və ya JPG variantına keçid var. Faylları birbaşa Figma, Canva və PowerPoint-ə əlavə edə bilərsən.

## Qovluqlar

- 01-logos — Rust, WebAssembly, AstroNot və NASA. Rust üçün tünd fon variantı var. WebAssembly üçün bənövşəyi, ağ və yazılı ağ variantlar var.
- 02-space-icons — 10 Lucide kosmos ikonu. SVG və 512 px PNG. Orijinal ikonlar qara rəngdədir, qalereyada tünd fon üzərində ağ göstərilir. SVG-ni Figma-da seçib rəngini #F8F9FB və ya #C4D6FA edə bilərsən.
- 03-space-images — 3840 × 2160 Whirlpool qalaktikası, Orion dumanlığı, Saturn, M51-in iki görünüşü, saytın qalaktika artwork-ü və ulduz fonu.
- 04-product-previews — saytın altı alətindən JPG önizləmələr və 1440 px enində PNG ekran görüntüləri.
