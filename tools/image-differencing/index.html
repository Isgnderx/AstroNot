    Export details

    Download the result as a FITS file: a DIFFERENCE image on the reference grid with the reference WCS, BUNIT and the direction (DIFFDIR), both observation IDs, a MASK image (0 valid, 1 invalid) and, when both images have variance, a VARIANCE image. Invalid pixels are NaN. The same result (aligned images, difference, overlap mask, WCS, unit and both observation IDs) is what Motion Detector will reuse.

    How the difference is computed

    Δ = target − reference for pixels that are valid in both images; a positive value means the target is brighter. Pixel values come from the calibrated data (BSCALE and BZERO applied once, BLANK and NaN invalid). A value of zero is valid.

    Same sky is decided from the WCS of each image; equal array sizes alone are never enough. On one verified pixel grid (every sample pixel at the same sky position within 0.01 pixel) the arrays are subtracted as they are, a pixel difference. On different grids the target is reprojected onto the reference grid by bilinear interpolation (the method of reproject_interp with order bilinear), and pixels the target does not cover, or whose interpolation touches an invalid pixel, are invalid. Real exposures taken on different dates sit about half a pixel apart, so this matters. Interpolation smooths the target and correlates its noise.

    Variance is combined as Var(Δ) = Var(target) + Var(reference) only when both files have a VARIANCE image in matching units, assuming independent errors; for a reprojected target the weights are squared and summed, and neighbouring pixels remain correlated. Otherwise the SNR stays empty. Units must match; only Jy prefixes such as kJy/sr and MJy/sr are converted. No PSF matching is applied, and background correction is off unless you choose it. Residuals from background, PSF and pixel-scale differences can look like real changes, and the scientific meaning of a difference depends on the band, the calibration and the alignment quality.

    FLAGS and other mask images are not interpreted; only NaN and BLANK pixels are excluded.
