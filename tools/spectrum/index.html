Spectrum Lab

Open a measured spectrum and read its flux density, uncertainties and archive flags against wavelength.

Spectrum file

CSV format

Choose a spectrum saved as CSV (comma, semicolon, tab or pipe separated, up to 25 MB). The file is read on this device and is not uploaded. The expected columns are wavelength in µm, flux in µJy and flux_err in µJy (the cell may be empty), plus optional lambda_width (µm), flags (integer bitmask), source_id, obs_id, mjd, ra, dec and method. Header names are matched without regard to case and other columns are kept. For any other CSV you can pick the columns and units yourself. Flux must be a flux density per unit frequency (Jy, mJy, µJy); flux per unit wavelength is a different quantity and is not supported.

          How to read this spectrum

          A spectrum here is a list of measurements, each at one wavelength with a flux density (the flux per unit frequency, in jansky units) and, when the file gives it, its uncertainty. Values stay exactly as the file states them. Changing a unit only rescales them: 100 µJy is 0.0001 Jy, 1.2 µm is 0.0000012 m, and the error and the width of a point are rescaled with the same factor as the point.

          Negative and zero fluxes are real measurements of a faint source plus noise, so they are kept and shown on the linear axis. A logarithmic flux axis cannot place them; they are then left out of the drawing, counted above the plot and kept in the table. An empty flux_err means the uncertainty is unavailable; it is shown as Unavailable and is not treated as zero.

          Several measurements may share one wavelength (for example repeat observations). Each is kept as its own point with its input line and observation ID. Different sources are never drawn together; choose the source above. The plot never joins points with a line.

          flags is read with the SPHEREx Spectrophotometry bit definitions from the IRSA Spectrophotometry Tool documentation. Bits the documentation names but does not describe are shown by name only, and a bit that is not documented is shown as an unknown bit with its raw value. The raw number is always shown too. The decoding only applies to flags written by that pipeline; for any other file, rely on the raw value.

          Whether a file really comes from the archive is not checked here. The example spectrum is generated for AstroNot and is not an archive result.
