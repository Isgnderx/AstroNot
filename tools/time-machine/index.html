      How comparisons are checked

      Time comes from DATE-OBS and MJD-OBS with TIMESYS (UTC when absent). If both are present and disagree by more than a second, neither is trusted. DATE is the time the file was written and is shown separately. A time you type is marked as entered manually. Times on different time scales are not ordered.

      Same sky is decided from the WCS of each image, not from file names. Linked pan and zoom and Blink need one verified pixel grid: equal array sizes and the same sky position for sample pixels in both images. Real exposures taken on different dates usually sit on slightly different grids; the optional alignment copies the nearest comparison pixel onto the reference grid for viewing and does not interpolate or change any value. Pixel values are read from the calibrated data and do not depend on contrast.

      The same file cannot be used as two epochs: identical pixel data are rejected as the same observation. Mask, variance and other HDUs are not applied. Blink shows at most two frames per second.
