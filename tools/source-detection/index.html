Source Detection

Identify sources in astronomical images and measure their positions.

Image

Choose a calibrated, uncompressed two-dimensional FITS image HDU (a local file read on this device, up to 4,194,304 pixels and 4,096 pixels per axis), or load the bundled SPHEREx cutout. The tool lists detected candidates: groups of connected pixels that stand out from the background. A candidate is not a catalog identification, and it can be a star, a galaxy, a blend, a ghost or a noise peak. Pixels that are NaN or BLANK are never used; zero is a valid value.

    Export details

    Download the candidates as a CSV for Catalog Cross-Match with the columns source_id, x_pixel, y_pixel, ra, dec, area_pixels, peak, flux_sum, flags, source_file, obs_id, hdu, pixel_origin. x_pixel and y_pixel are FITS pixel numbers (pixel_origin = 1: the center of the first pixel is (1, 1)). ra and dec are degrees in ICRS from the centroid, empty when the image has no usable WCS. hdu counts from 0 (the primary HDU). The same-named parameters file records the method, threshold and its unit, and every setting. Source IDs belong to one run and change when the settings change.

    How candidates are found

    Valid pixels are the finite values after BSCALE, BZERO and BLANK are applied. The background is a sigma-clipped median (3 σ, up to 10 passes), either one value or a mesh of boxes whose medians are median-filtered and interpolated. The noise σ is 1.4826 × the median absolute deviation of the same clipped sample, or √variance from a VARIANCE image when the file has one in the square of the image unit. A threshold of 3 σ is therefore a different brightness in a noisier image, or in a noisier part of a mesh or VARIANCE image; the result shows the level in image units.

    Pixels above the threshold are grouped into 8-connected segments, and segments with fewer than the minimum number of pixels are dropped. Optional Gaussian smoothing is a normalized convolution over valid pixels, with the noise propagated for independent pixels (real noise is often correlated, so the S/N of a smoothed image is approximate). A segment is split where two peaks are separated by a valley at least the chosen number of σ and at least 10% of the lower peak deep, with at least the minimum number of pixels on each side. A shared segment is flagged blended.

    The centroid is flux-weighted over the segment pixels of the unsmoothed background-subtracted values (negative values count as zero). Peak and flux sum are in the image unit; for surface brightness such as MJy/sr the flux sum is not a flux density. Flags mean: edge (touches the image border), masked neighbour (next to NaN, BLANK or unusable pixels), saturated (reaches the saturation level, tested only when you or the header give one) and blended. FLAGS and other mask images are not interpreted. No photometry, PSF fitting, star-galaxy separation or catalog matching is done here.
